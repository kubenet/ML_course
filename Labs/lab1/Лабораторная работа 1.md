# 2. Краткий теоретический материал

## 2.1. Что такое классификация изображений?

Классификация изображений — это задача, в которой нейронная сеть должна ответить на вопрос:

```text
Что изображено на картинке?
```

Например:

- кошка;
- собака;
- автомобиль;
- цветок;
- ноутбук.

Модель получает изображение и возвращает один или несколько предполагаемых классов.

---

## 2.2. Что такое нейронная сеть?

Нейронная сеть — это математическая модель, которая обучается находить закономерности в данных.

Для изображений чаще всего используют сверточные нейронные сети — **CNN** от англ. *Convolutional Neural Network*.

Сверточная сеть постепенно выделяет признаки изображения:

1. простые линии и границы;
2. текстуры;
3. части объектов;
4. целые объекты.

---

## 2.3. Что такое предобученная модель?

Предобученная модель — это модель, которую уже обучили на большом наборе изображений.

В данной работе используется модель, обученная на датасете **ImageNet**. Этот датасет содержит миллионы изображений и 1000 классов.

Преимущества предобученной модели:

- не нужно обучать модель самостоятельно;
- модель уже умеет распознавать много объектов;
- можно быстро получить результат;
- модель можно использовать как основу для дальнейших задач.

---

## 2.4. Что происходит во время инференса?

Инференс — это этап, когда обученная модель уже не обучается, а только делает предсказания.

Схема работы:

```text
Изображение → предобработка → нейронная сеть → вероятности классов → ответ модели
```

---

## 2.5. Зачем нужна предобработка изображения?

Перед подачей изображения в модель его нужно подготовить.

Обычно выполняются следующие шаги:

1. Привести изображение к цвету RGB.
2. Изменить размер.
3. Преобразовать изображение в числовой тензор.
4. Нормализовать значения пикселей.

В `torchvision` готовая предобработка часто уже доступна через объект весов:

```python
transform = weights.transforms()
```

---

## 2.6. Что возвращает модель?

Модель возвращает числа, которые называются **логиты**.

Сами по себе логиты не являются вероятностями. Чтобы получить вероятности, используется функция `softmax`.

```python
probabilities = torch.softmax(logits, dim=1)
```

После этого каждое значение находится в диапазоне от 0 до 1.

---

## 2.7. Что такое top-1 и top-5?

Так как модель может выдавать вероятности для 1000 классов, удобно смотреть только несколько самых вероятных вариантов.

- **top-1** — один класс с максимальной вероятностью;
- **top-5** — пять классов с наибольшими вероятностями.

Например:

| Место | Класс | Вероятность |
|---|---|---:|
| 1 | golden retriever | 0.78 |
| 2 | Labrador retriever | 0.11 |
| 3 | cocker spaniel | 0.04 |
| 4 | tennis ball | 0.02 |
| 5 | sports car | 0.01 |

## Ячейка 5. Функция предсказания

```python
def predict_image(image_path, top_k=5):
    image = Image.open(image_path).convert("RGB")
    x = transform(image).unsqueeze(0).to(device)

    with torch.inference_mode():
        logits = model(x)

    probs = torch.softmax(logits, dim=1)[0]
    top_probs, top_ids = torch.topk(probs, k=top_k)

    top_classes = [categories[idx] for idx in top_ids.tolist()]
    top_values = top_probs.tolist()

    return top_classes, top_values
```

## Ячейка 6. Создание таблицы результатов

```python
results = []

for image_path, true_label in zip(image_paths, true_labels):
    classes, probs = predict_image(image_path, top_k=5)

    results.append({
        "file": Path(image_path).name,
        "true_label": true_label,
        "top1": classes[0],
        "top1_prob": round(probs[0], 3),
        "top5": ", ".join(classes),
        "top1_correct": true_label == classes[0],
        "top5_correct": true_label in classes
    })

df = pd.DataFrame(results)
df
```
